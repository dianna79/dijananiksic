# Images

Use this folder for portfolio images.

Suggested files:

- `profile.jpg` - your portrait/photo for the About section.
- `intro.jpg` - optional Intro image.
- `work-project.jpg`, `work-product.jpg`, `work-localization.jpg`, `work-operations.jpg` - optional Work card images.

The current site uses `profile.jpg` in the About section. To replace it, add a new image here and update the image source in `index.html`, for example:

```html
<img src="images/profile.jpg" alt="Dijana Niksic">
```
